01

Python คืออะไร?

Python คือภาษาคอมพิวเตอร์ที่ใช้งานง่าย จัดเป็นภาษาระดับสูง (High-level Language) อ่านและเขียนได้ใกล้เคียงภาษาอังกฤษทั่วไป จึงเหมาะสำหรับผู้เริ่มต้นเขียนโปรแกรม

นำไปประยุกต์ใช้งานได้หลากหลาย เช่น

  • เขียนโปรแกรมทั่วไป (Software Development)
  • วิเคราะห์ข้อมูล (Data Analysis)
  • พัฒนาเว็บไซต์ (Web Development)
  • สร้างเกม (Game Development)
02

การแสดงผล และรับข้อมูล

แสดงผล — print()

แสดงข้อความออกทางหน้าจอprint("ข้อความ")

# ตัวอย่าง
print("Hello, Python!")
# ผลลัพธ์: Hello, Python!

รับข้อมูล — input()

รับข้อมูลจากผู้ใช้ (ได้ชนิด str เสมอ)input("ข้อความ")

# ตัวอย่าง
name = input("ชื่อของคุณ: ")
print("สวัสดี", name)
03

ตัวแปร (Variable)

ตัวแปร คือ พื้นที่สำหรับเก็บข้อมูล โดยไม่ต้องประกาศชนิดข้อมูลล่วงหน้า รูปแบบ: ชื่อตัวแปร = ข้อมูล

name = "Alex"       # ข้อความ
age = 14            # ตัวเลข
height = 165.5       # ทศนิยม
is_student = True    # จริง/เท็จ

กฎการตั้งชื่อตัวแปร

  • ต้องขึ้นต้นด้วยตัวอักษร (a-z, A-Z) หรือเครื่องหมาย _ เท่านั้น
  • ห้ามขึ้นต้นด้วยตัวเลข เช่น 1name ผิด
  • ห้ามมีช่องว่างหรืออักขระพิเศษ เช่น - @ ! % (ใช้ _ แทนช่องว่างได้)
  • ตัวพิมพ์เล็ก-ใหญ่มีผลต่างกัน เช่น Name กับ name ถือเป็นคนละตัวแปร
  • ห้ามตั้งชื่อซ้ำกับ คำสงวน (Keyword) ของภาษา Python

คำสงวน (Reserved Words) ห้ามนำมาตั้งชื่อตัวแปร

FalseNoneTrueandasassert asyncawaitbreakclasscontinuedef delelifelseexceptfinallyfor fromglobalifimportinis lambdanonlocalnotorpassraise returntrywhilewithyield

05

ตัวดำเนินการทางคณิตศาสตร์

ตัวดำเนินการความหมายตัวอย่าง
+บวก5 + 3 = 8
-ลบ5 - 3 = 2
*คูณ5 * 3 = 15
/หาร (ได้ทศนิยม)5 / 2 = 2.5
//หารเอาแต่จำนวนเต็ม5 // 2 = 2
%หารเอาเศษ5 % 2 = 1
**ยกกำลัง2 ** 3 = 8

ลำดับการดำเนินการ (ทำก่อน-หลัง)

  • ( ) วงเล็บ — ทำก่อนเสมอ
  • ** ยกกำลัง
  • * / // % คูณ หาร (ซ้ายไปขวา)
  • + - บวก ลบ (ซ้ายไปขวา)

ตัวอย่างวิธีคำนวณทีละขั้น

2 + 3 * 4 ** 2 - 6 / 2
4 ** 2 = 16 → 2 + 3 * 16 - 6 / 2
3 * 16 = 48 → 2 + 48 - 6 / 2
6 / 2 = 3.0 → 2 + 48 - 3.0
2 + 48 - 3.0 = 47.0

07

คำสั่งเงื่อนไข (if-elif-else)

score = int(input("คะแนน: "))

if score >= 80:
    print("เกรด A")
elif score >= 50:
    print("เกรด B")
else:
    print("เกรด C")

การทำงาน

  • ถ้า score >= 80 → ทำงานบรรทัดใต้ if
  • ไม่ใช่ แต่ score >= 50 → ทำงานบรรทัดใต้ elif
  • ไม่เข้าเงื่อนไขใดเลย → ทำงานบรรทัดใต้ else
ตรวจเงื่อนไขจากบนลงล่างทีละบรรทัด และจะทำงานเพียงเงื่อนไขเดียวที่ตรงก่อนเท่านั้น
08

การวนซ้ำ (Loop)

for loop

for i in range(1, 6):
    print(i)
# แสดง 1 ถึง 5

range(เริ่ม, จบ) เริ่มต้นที่ "เริ่ม" และจบก่อนถึง "จบ" เพิ่มทีละ 1

while loop

i = 1
while i <= 5:
    print(i)
    i = i + 1
# แสดง 1 ถึง 5

ทำงานซ้ำ "ตราบใดที่" เงื่อนไขยังเป็นจริง ต้องเพิ่มค่าตัวแปรเองไม่ให้วนไม่รู้จบ

09

โครงสร้างข้อมูล (Data Structure)

List (รายการ)

เก็บข้อมูลได้หลายค่าในตัวแปรเดียว เรียงลำดับ และแก้ไขได้

fruits = ['apple', 'banana', 'orange']
print(fruits[0])   # apple
print(len(fruits)) # 3

Dictionary (พจนานุกรม)

เก็บข้อมูลเป็นคู่ key : value ค้นหาค่าด้วย key

student = {'name': 'Alex', 'age': 14}
print(student["name"]) # Alex

ฟังก์ชัน (Function)

ฟังก์ชัน คือ การสร้างชุดคำสั่งเก็บไว้เป็นก้อนเดียว แล้วเรียกใช้งานซ้ำได้ตามต้องการ ช่วยลดการเขียนโค้ดซ้ำๆ

def greet(name):
    print("สวัสดี", name)

greet("มายด์")  # เรียกใช้งาน

ตัวอย่างโปรแกรมง่าย ๆ
